slaplog — sample reports

Two complete HTML reports produced by slaplog, served as static pages.

Simulated incident report A full incident snapshot: latency, errors, replication, bind failures and the diagnosis the report makes obvious at a glance. Synthetic sample report Generated from a small reproducible log set that tells a four-day incident story.
Both reports contain only reserved names (example.com / example.org / example.net, RFC 2606) and documentation addresses (RFC 5737).
