slaplog WebAssembly

100% local — nothing uploaded
OpenLDAP slapd access-log analyzer — parses, aggregates and reports BIND / SRCH / write operations, results and errors, search bases, filters, attributes, sessions, replication CSN events and operation timings. One or more log files, in text (ANSI), HTML, JSON or jMeter/LoadRunner replay form.
Drop OpenLDAP slapd access logs here
or click to choose files, or add a folder — a folder is walked recursively, which is how the logs of several servers are gathered in one gesture (logs/*/access.log). Selections add up, and the files are analysed sequentially into a single report. Plain, .gz, .bz2 and .xz are all supported.
Output
Input log format is always auto-detected, per line — debug, syslog-utc, syslog-localtime, rfc3339-utc, ol26, rfc3339 and syslog, mixed freely.
Sections & detail
all includes everything — selecting any individual section removes all.
